# khw_hub 使用文档(M1)

> khw_hub 是一款本地相机应用:配合 **ESP32-S3-CAM** 摄像头,在同一 WiFi 下即可查看实时画面、截图、录像。无需注册账号,数据不经过云端,全部在局域网内完成。

## 1. 快速上手(约 3 分钟)

1. **装好 App** 与 **烧好固件**(首次使用请先看第 2 节与"固件准备")。
2. **给设备通电**:设备开机会先进入"配网模式",手机 WiFi 列表会出现一个名为 `ESP32-CAM-Setup` 的热点。
3. **配网**:打开 khw_hub → 右下角 `+` → 把家里 WiFi 的名称和密码填进去 → 连接配网。设备重启后自动连上家里 WiFi,手机也自动回到家里 WiFi。
4. **看画面**:回首页,设备卡片出现后点开即可看到实时画面。

> 固件路径:`esp32-s3-cam/firmware/board-camera/board-camera.ino`(需用 Arduino IDE 按文件顶部注释的烧录设置编译烧录;**固件 0.2.6**,支持"长按 BOOT 4 秒清除凭据回配网模式")。
> App 安装包:项目构建产物 `app-debug.apk`(由开发者提供,或按项目 README 用 Android Studio 构建)。

## 2. 配网(第一次使用)

1. 确认设备已通电、处于配网模式(手机能搜到 `ESP32-CAM-Setup` 热点)。
2. 打开 khw_hub,App 启动时会请求"附近设备 / 位置"权限,请允许(用于搜索同一 WiFi 下的设备)。
3. 点首页右下角的 **`+`** 进入配网页。
4. **设备热点名称**:保持默认 `ESP32-CAM-Setup`,一般不用改。
5. **家庭 WiFi**:填写你家 WiFi 的**准确名称(区分大小写)**和密码。也可以点 **"扫描附近网络"**,在弹出的浮窗里**点选**要连的 WiFi(点哪行选哪个,选中行高亮打勾),再补密码。
6. 点 **"连接设备并配网"**,稍等片刻会提示"配网成功,设备正在重启…",然后**自动返回首页**(无需手动点完成)。

**注意事项**
- 设备热点**只用于配网**这一步,配网完成后设备会重启并连上你家 WiFi,热点随之消失——这是正常的。
- **换 WiFi 或重新配网**:开机后**长按设备上的 BOOT 键约 4 秒**,设备清除已存的 WiFi 凭据并重启,重新进入配网模式(手机能再次搜到 `ESP32-CAM-Setup`)。单纯断电重启不会清除凭据。
- SSID 大小写、空格要照抄;密码错了设备会回到配网模式,重新配一次即可。
- 建议靠近路由器配网。

## 3. 日常使用

### 3.1 查看实时画面
- 首页会以卡片列出设备,卡片上显示设备名与在线状态(绿点=在线,灰点=离线,黄点=连接中)。
- **点卡片**进入全屏详情页看实时画面。刚进入可能有 1~2 秒黑屏,是相机预热,属正常。
- 退出详情页即自动断开视频,不耗流量。

### 3.2 截图
- 在详情页点底部 **"截图"**,画面会以 JPG 存入相册的 **`Pictures/khw_hub`**。
- 旧手机(Android 9 及以下)首次截图会弹"存储权限",允许即可。

### 3.3 录像
- 在详情页点 **"录像"**,按钮变红,开始录制;**再点一次**停止并保存。
- 视频保存在相册 **`Movies/khw_hub`**(MP4 格式)。
- 录像**没有声音**,这是硬件限制(摄像头板没有麦克风),不是故障。
- 录像中途直接退出页面或锁屏,会自动停止并保存,不必担心丢文件。

### 3.4 摄像头设置
- 详情页右上角 **⚙** 进入设置页,可调:
  - **分辨率**:320×240 ~ 1600×1200。越高越清晰,但画面会变慢、更占带宽。**切换后画面大小/清晰度会明显变化**(如 320×240 与 1600×1200 差别很大),如果换分辨率后画面看着没变化,说明固件版本过旧,需升级到 0.2.5。
  - **画质**:数值越小越清晰(4~63)。
  - **垂直翻转 / 水平镜像**:画面装反时打开。
- 点 **"保存并应用"** 立即生效,断电重启也不会丢。

### 3.5 重命名 / 删除设备
- **重命名**:设置页 → "重命名" → 输入新名字 → 确定。改后首页立即更新,重启 App 仍在。
- **删除设备**:设置页 → "删除设备" → 确认。删除后首页不再显示,App 同时通知设备**清除 WiFi 凭据并重启回配网模式**(真正断网),设备重新通电也不会自动回来。
  - 想找回?**重新配网一次即可**(设备本身不会丢失任何配置,只是从 App 里隐藏)。

## 4. 常见问题(FAQ)

| 问题 | 怎么办 |
|---|---|
| 首页找不到设备 | 确认手机与设备在**同一个 WiFi**;确认设备已配网成功(配网成功 = 热点 `ESP32-CAM-Setup` 消失);确认 App 的"附近设备 / 位置"权限已开启。等几秒再刷新 |
| 配网时"连接设备热点失败" | 确认设备已开机、热点名输入正确(区分大小写);在手机设置里手动连一次 `ESP32-CAM-Setup` 再回 App 重试;若之前已配过网,设备不会开热点——**长按设备 BOOT 键约 4 秒清除凭据**后会自动重进配网模式 |
| 扫描附近网络没结果 | 弹窗打开后会自动每 6 秒重扫一次,稍等几秒;确认 App 的"附近设备 / 位置"权限已开启(可在系统设置里检查);也可点弹窗里的"刷新" |
| 配网成功但设备连不上家里 WiFi | 密码错误(设备会退回配网模式,重新配);检查家里 WiFi 是否为 2.4GHz |
| 详情页一直黑屏/转圈 | 等相机预热几秒;如果画面分辨率太高,去设置页调低(如 640×480)再试;退出重进详情页 |
| 录像没有声音 | 正常——摄像头板没有麦克风 |
| 录像提示"无画面" | 先确认画面已显示出来,再点录像(首帧 5 秒内没到会取消) |
| 手机连不上设备热点 | 设备可能已经完成配网、热点已关闭。要重新配网:开机后**长按设备上的 BOOT 键约 4 秒**,设备会清除已存的 WiFi 凭据并重启,重新进入配网模式(手机会再次看到 `ESP32-CAM-Setup` 热点);再不行就重烧固件 |

## 5. 安全与限制(请如实了解)

- khw_hub 通过局域网直连设备,**没有账号、没有云服务、没有端到端加密**。
- 请只在**可信的家庭 / 实验室网络**中使用;同一网络里的其他设备可访问到你的摄像头。
- 本版为实验室开发版(M1),后续版本会加入设备访问令牌。
