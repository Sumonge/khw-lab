# khw_hub 使用文档(M2)

> khw_hub 是一款本地设备管理应用:配合 **ESP32-S3-CAM 摄像头**(查看实时画面、截图、录像)与 **XIAO ESP32-C3 电磁锁**(远程开锁/锁定),在同一 WiFi 下即可使用。无需注册账号,数据不经过云端,全部在局域网内完成。

## 1. 快速上手(约 3 分钟)

1. **装好 App** 与 **烧好固件**(首次使用请先看第 2 节与"固件准备")。
2. **给设备通电**:
   - **摄像头**:开机会先进入"配网模式",指示灯**蓝色呼吸慢闪**,手机蓝牙能看到名为 `KHW-CAM-xxxx` 的配网广播,同时手机 WiFi 列表会出现热点 `ESP32-CAM-Setup`。
   - **电磁锁**:同上,配网广播名 `KHW-LOCK-xxxx`,热点名 `KHW-LOCK-Setup`。
3. **配网**:打开 khw_hub → 右下角 `+`。**推荐用"蓝牙配网"**(选到设备→填家庭 WiFi→下发,不用切热点);蓝牙不顺畅时切"热点配网"。
4. **使用**:回首页出现设备卡片 → 摄像头点开看画面;电磁锁点开点"开锁/锁定"。

> 固件路径:
> - 摄像头 `esp32-s3-cam/firmware/board-camera/board-camera.ino`(**固件 0.3.0**)
> - 电磁锁 `esp32-s3-cam/firmware/board-lock/board-lock.ino`(**固件 0.2.0**)
> 均需用 Arduino IDE 按文件顶部注释的烧录设置编译烧录。
> App 安装包:项目构建产物 `app-debug.apk`(由开发者提供,或按项目 README 用 Android Studio 构建)。

## 2. 配网(第一次使用)

设备通电后处于**配网模式**(指示灯蓝色呼吸)。配网有两种方式:

### 2.1 蓝牙配网(推荐)
1. 打开 khw_hub,App 启动时会请求"附近设备 / 位置"权限,请允许(蓝牙扫描需要)。
2. 点首页右下角 **`+`** 进配网页,选 **"蓝牙配网"**。
3. 扫描出待配网设备后,点选你的设备(摄像头显示"摄像头 / KHW-CAM-xxxx",电磁锁显示"电磁锁 / KHW-LOCK-xxxx")。
4. **家庭 WiFi**:填写你家 WiFi 的**准确名称(区分大小写)**和密码,或点 **"扫描附近网络"** 在浮窗里**点选**。
5. 下发后设备自动连接并重启入网,App 提示"配网成功"。

### 2.2 热点配网(兜底)
1. 配网页选 **"热点配网"**。
2. **设备热点名称**:摄像头保持默认 `ESP32-CAM-Setup`,电磁锁为 `KHW-LOCK-Setup`,一般不用改。
3. 填写**家庭 WiFi**名称(区分大小写)和密码,点 **"连接设备并配网"**,提示"配网成功,设备正在重启…"后自动返回首页。

**注意事项**
- 设备热点/蓝牙广播**只用于配网**这一步,配网完成后设备重启并连上你家 WiFi,热点随之消失——这是正常的。
- **换 WiFi 或重新配网**:开机后**长按设备上的 BOOT 键约 4 秒**,设备清除已存的 WiFi 凭据和配对令牌并重启,重新进入配网模式。单纯断电重启不会清除凭据。
- SSID 大小写、空格要照抄;密码错了设备会回到配网模式,重新配一次即可。
- 建议靠近路由器配网。

## 3. 日常使用

### 3.1 查看实时画面(摄像头)
- 首页以卡片列出设备,卡片显示设备名与在线状态(绿点=在线,灰点=离线,黄点=连接中)。
- **点摄像头卡片**进入全屏详情页。刚进入可能有 1~2 秒黑屏,是相机预热,属正常。
- 退出详情页即自动断开视频,不耗流量。

### 3.2 截图(摄像头)
- 详情页点底部 **"截图"**,画面以 JPG 存入相册 **`Pictures/khw_hub`**。
- 旧手机(Android 9 及以下)首次截图会弹"存储权限",允许即可。

### 3.3 录像(摄像头)
- 详情页点 **"录像"**,按钮变红开始录制;**再点一次**停止并保存到相册 **`Movies/khw_hub`**(MP4)。
- 录像**没有声音**,这是硬件限制(摄像头板没有麦克风),不是故障。
- 录像中途退出页面或锁屏,会自动停止并保存。

### 3.4 摄像头设置
- 详情页右上角 **⚙** 进设置页:分辨率(320×240~1600×1200,越高越清晰但越慢越占带宽)、画质(数值越小越清晰)、垂直翻转/水平镜像(画面装反时打开)。
- 点 **"保存并应用"** 立即生效,断电重启不丢。

### 3.5 电磁锁:开锁 / 锁定
- **点电磁锁卡片**进入详情页:大按钮"开锁/锁定"(按当前状态自动切换),下方另有独立的 **"锁定"** 与 **"开锁"** 按钮。
- 每次操作后页面状态即时更新,并显示**状态变更时间**(刚配完网未同步时钟时显示"设备运行 N 秒",稍后会自动变为具体时间)。
- 详情页开着时,其他端(另一台手机等)操作锁,本页也会**实时刷新**,无需手动刷新。
- **指示灯**:开机自检白色快闪 3 次;配网模式蓝色呼吸;配网中蓝色常亮;连接 WiFi 黄色快闪;在线绿色常亮;每次执行开/锁动作(状态实际变化)橙色闪一下。

### 3.6 电磁锁设置:自动回锁
- 详情页右上角 **⚙** 进设置页,可设 **"自动回锁时长(秒)"**:开锁后超过该时长无人再操作,设备**自动重新上锁**。设 **0 关闭**(默认)。
- 断电重启设置保持;若设为 0,开锁后**不会**自动回锁,需手动或断电。
- **注意硬件特性**:锁由 3V 电源驱动,**断电即为开锁**;无状态反馈线,App 显示的是设备记录的最后状态。

### 3.7 重命名 / 删除设备
- **重命名**:设置页 → "重命名" → 输入新名字 → 确定。改后首页立即更新,重启 App 仍在。
- **删除设备**:设置页 → "删除设备" → 确认。删除后首页不再显示,App 同时通知设备**清除 WiFi 凭据和令牌并重启回配网模式**(真正断网),设备重新通电也不会自动回来。
  - 想找回?**重新配网一次即可**(设备本身不会丢失配置,只是从 App 里隐藏)。
- **提示"设备未配对或令牌失效"**:说明设备已被重置/删除过(令牌变了),请**删除该设备后重新配网**。

## 4. 常见问题(FAQ)

| 问题 | 怎么办 |
|---|---|
| 首页找不到设备 | 确认手机与设备在**同一个 WiFi**;确认设备已配网成功(配网成功 = 热点消失、指示灯绿);确认 App 的"附近设备 / 位置"权限已开启。等几秒再刷新 |
| 配网时"蓝牙扫描不到设备" | 确认设备已开机且在配网模式(蓝色呼吸灯);确认 App 蓝牙权限已开启;可用 **"热点配网"** 兜底 |
| 配网时"连接设备热点失败" | 确认设备已开机、热点名输入正确(区分大小写);在手机设置里手动连一次 `ESP32-CAM-Setup`(或 `KHW-LOCK-Setup`)再回 App 重试;若之前已配过网,设备不会开热点——**长按设备 BOOT 键约 4 秒清除凭据**后会自动重进配网模式 |
| 扫描附近网络没结果 | 弹窗每 6 秒自动重扫一次,稍等几秒;确认 App 权限已开启;也可点"刷新" |
| 配网成功但设备连不上家里 WiFi | 密码错误(设备会退回配网模式,重新配);检查家里 WiFi 是否为 2.4GHz |
| 摄像头详情页一直黑屏/转圈 | 等相机预热几秒;分辨率过高就调低(如 640×480)再试;退出重进详情页 |
| 录像没有声音 | 正常——摄像头板没有麦克风 |
| 录像提示"无画面" | 先确认画面已显示出来,再点录像(首帧 5 秒内没到会取消) |
| 电磁锁点按钮没反应 | 确认设备在线(卡片绿点);设备可能刚断电——**断电即开锁**,上电后 App 会重新读到"已锁定" |
| 电磁锁"状态变更时间"显示"运行 N 秒" | 正常——设备时钟刚配网还没同步,稍等会自动显示具体时间 |
| 电磁锁提示"设备未配对或令牌失效" | 设备被重置过或令牌已变,按提示**删除设备后重新配网** |
| 手机连不上设备热点 | 设备可能已完成配网、热点已关闭。要重新配网:开机后**长按设备上的 BOOT 键约 4 秒**,设备清凭据重启回配网模式;再不行就重烧固件 |

## 5. 安全与限制(请如实了解)

- khw_hub 通过局域网直连设备,**没有账号、没有云服务、没有端到端加密**。
- 设备访问凭据(令牌)在配网时由设备生成并保存于 App,用于本地鉴权;**令牌只在一台设备的配网过程中下发给那台设备**,设备被重置后令牌失效,需重新配网。
- 请只在**可信的家庭 / 实验室网络**中使用;同一网络里的其他设备可访问到你的摄像头。
- 电磁锁为**无状态反馈**的低成本方案:断电即开锁,App 显示的是设备记录状态,不能作为唯一安全凭据使用。
- 本版为实验室开发版(M2),仅覆盖摄像头与电磁锁两款产品。
