# Lab Hub 测试文档(M1)

> 范围:ESP32-S3-CAM 固件(0.2.5)+ Android App(Lab Hub)端到端硬件验收。逐条跑完 12 个用例,全部通过视为 M1 验收完成。
> 契约依据:`esp32-s3-cam/firmware/board-camera/board-camera.ino` 与 `khw_lab` App 源码。

## 0. 准备

**硬件 / 环境**
- Android 手机 ×1(建议 Android 10+,兼容 8.0+)
- ESP32-S3-CAM ×1(GC2145,ESP32-S3-EYE 风格引脚)+ 数据线
- 家庭路由器 ×1(2.4GHz WiFi)

**固件烧录设置**(Arduino IDE)
- 板型 ESP32S3 Dev Module;Flash 16MB;OPI PSRAM;USB CDC On Boot = **Disabled**;Upload Speed 115200
- 固件路径:`esp32-s3-cam\firmware\board-camera\board-camera.ino`

**App**
- APK:`khw_lab\app\build\outputs\apk\debug\app-debug.apk`(可先不装,配网时再用)

## 2. 详细用例

### T01 烧录与启动
**前置**:Arduino IDE 已装 ESP32-S3 板支持包。
**步骤**:
1. 按上表烧录设置编译并烧录 `board-camera.ino`。
2. 打开串口监视器(115200),给设备上电。
**预期**:日志出现 `Camera init ok`(或 `initCamera` 成功路径)→ 无凭据时打印 `AP mode: ESP32-CAM-Setup (192.168.4.1)`,然后 `HTTP server started`;无 `Camera init failed`。
**结果**:✔ 日志符合预期,`Camera init ok`、AP 模式与 HTTP server 均正常。

### T02 配网
**前置**:设备已在 AP 模式(手机能看到 `ESP32-CAM-Setup` 热点);手机已装 APK 并授权(App 首次启动会请求"附近设备"/定位权限)。
**步骤**:
1. 打开 Lab Hub → 首页右下角 `+` 进配网页。
2. 设备热点名称保持默认 `ESP32-CAM-Setup`;填写家庭 WiFi 名称(SSID)与密码,注意**大小写**。
3. 点"连接设备并配网"→ 等 App 提示"配网成功,设备正在重启…"→ **自动返回首页**(0.2.2 起无需手动点完成)。
4. 串口观察设备日志。
**预期**:设备重启后打印 `WiFi connected, IP: 192.168.x.x` 与 `UDP discover listening on port 3333`;手机自动回到家庭 WiFi;App **自动返回首页**并开始发现设备。
**结果**:✔ 配网成功,设备入网并自动返回首页。

### T03 发现
**前置**:T02 完成,设备与手机同处家庭 WiFi。
**步骤**:停留在首页 ≥10 秒。
**预期**:卡片在 ≤5 秒(mDNS)或 ≤6 秒(UDP 兜底)内出现,名称形如 `esp32cam-xxxxxx`,状态点**在线**(绿色)。
**结果**:✔ 卡片在预期时间内出现,状态在线。

### T04 看流
**前置**:T03 设备在线。
**步骤**:点击卡片进入详情页,停留观察;随后退出详情页再进入一次。
**预期**:几秒预热后出**实时画面**(默认 1024×768);退出重进正常,无卡死;画质肉眼可读。
**结果**:✔ 出图正常,退出重进正常。

### T05 截图
**前置**:详情页有画面。
**步骤**:点底部"截图"按钮。
**预期**:Snackbar 提示"截图已保存";相册 `Pictures/LabHub` 出现 `khwlab_capture.jpg`(可打开)。**API ≤28(Android 9-)**:首次会弹存储权限,允许后再截。
**结果**:✔ 截图已保存,相册可打开。

### T06 录像
**前置**:详情页有画面。
**步骤**:
1. 点"录像"→ 按钮变"停止"(红)。
2. 录约 5 秒 → 点"停止"。
3. 在系统"文件/相册"的 `Movies/LabHub` 找 MP4(名称 `khwlab_rec_时间戳.mp4`)并播放。
**预期**:MP4 存在且可播放,画面与实时一致,**无声音属正常**(板子无麦克风)。
**附加(可选)**:在详情页**无画面**(如设备断电)时点录像,≤5 秒应提示"无画面,无法录像"并停止。
**结果**:✔ MP4 存在且可播放,画面与实时一致(无声音属正常)。

### T07 设置
**前置**:详情页可进"设置"(右上角 ⚙)。
**步骤**:
1. 分辨率改为 `1600×1200`,画质拖小,打开"垂直翻转",点"保存并应用"。
2. 回详情页看画面;断电重启后再进设置页读值。
3. **反复进出设置页 3+ 次(含从视频页直接进)确认不闪退**(第 9 轮修复:内层不再嵌套 verticalScroll)。
4. **(0.2.4)逐个切换分辨率 `320×240 → 640×480 → 800×600 → 1024×768 → 1600×1200`,每次保存后回详情页看画面是否正常、无花屏/多画面伪影**。
5. **(0.2.4)单独勾"垂直翻转"保存、回详情页看是否上下翻转;再勾"水平镜像"看是否左右翻转**。
**预期**:保存后画面**立即**变化(分辨率/翻转生效);重启后设置仍保持(NVS 持久化);设置页可反复进出,不闪退。**0.2.5:各分辨率切换后画面正常无花屏伪影,且各档分辨率实际生效(320×240 与 1600×1200 画面尺寸/清晰度差异明显);vflip/hmirror 分别独立生效**(0.2.5 起 `rebuildCamera` 每次从全局设置同步 `frame_size/quality` 再 deinit+init;翻转/镜像用寄存器级 `set_reg(0x17)` 且在每次相机重建后重放)。
**结果**:✔ 分辨率逐档切换画面正常、尺寸随档位明显变化,无花屏;vflip/hmirror 单独勾选各自生效;断电重启后设置保持;设置页反复进出 3+ 次不闪退。

### T08 重命名
**前置**:首页有设备卡。
**步骤**:详情页 ⚙ → 设置页 → "重命名" → 输入新名字 → 确定;强制杀 App 后重启再进首页。
**预期**:首页卡片名**立即**更新,App 重启后仍显示新名(本地持久化)。**(第 8 轮修复)点确认的瞬间,设置页标题与"设备信息"里的名称立刻变为新名,并弹 Toast「已重命名为「X」」,无需退回首页**。
**结果**:✔ 重命名即时生效(标题 + 设备信息立刻变,弹 toast),杀 App 重进仍是新名。

### T09 删除与找回
**前置**:T08 已改名。
**步骤**:
1. 设置页 → "删除设备" → 确认。
2. 回首页等 ≥12 秒;重启 App 再等。
3. 再次执行一次完整配网(T02)重新下发凭据。
**预期**:删除后首页卡片**消失且不自动回来**;重新配网成功后,设备重新出现在首页(**找回**,改名已重置为默认)。
**结果**:✔ 删除后卡片消失,重新配网后设备找回。

### T10 离线
**前置**:首页设备在线。
**步骤**:拔掉设备电源,首页停留观察;重新上电再看。
**预期**:断电后卡片约 **≤10 秒**内状态变"离线"(灰色);恢复供电后自动回"在线"(无需重启 App)。
**结果**:✔ 断电 ≤10 秒变离线,恢复供电自动回在线。

### T11 双发现通道(可选用例)
**前置**:T03 通过;愿意重烧一版固件。
**步骤**:临时注释 `board-camera.ino` 里 `MDNS.begin(...)` / `addService(...)`,烧录后重复 T02→T03。
**预期**:mDNS 关闭时,App 仍能在 ≤6 秒内靠 **UDP 兜底**发现设备(验证 3333 通道独立可用)。完成后**恢复 mDNS 并重烧**。
**结果**:✔ UDP 兜底通道独立可用(可选用例,已按流程恢复 mDNS)。

### T12 录像收尾
**前置**:设备在线,详情页有画面。
**步骤**:
1. 点"录像",录 3 秒后**直接返回首页**(或锁屏)再回来。
2. 检查 `Movies/LabHub` 是否有 MP4;用 `adb shell ls /data/data/com.khwlab.hub/cache`(或手机文件管理)确认缓存目录无残留 `khwlab_rec_*.mp4`。
**预期**:退页/锁屏时录像**自动停止并保存**(ON_STOP 兜底);缓存目录无半成品残留。
**结果**:✔ 退页时录像自动停止保存,无残留。

## 3. 排障速查

| 症状 | 原因 / 处置 |
|---|---|
| 配网"连接设备热点失败" | 热点未开或名称输错(SSID 大小写敏感);手动连一次 `ESP32-CAM-Setup` 再配;部分手机需靠近设备。**若设备已配过网不会开热点:长按 BOOT 约 4 秒清凭据回配网模式(0.2.2)** |
| 扫描附近网络没结果 | 权限未开(33+ 需"附近设备",旧版需定位);弹窗每 6s 自动重扫,也可点"刷新" |
| 配网成功但设备没入网 | 密码错误 → 设备回 AP 模式,重配;检查家庭 WiFi 是否 2.4GHz |
| 首页一直找不到设备 | 手机与设备是否**同一 WiFi**;App 发现权限是否授权(33+ 需"附近设备"权限);若怀疑 mDNS,验证 T11(UDP 兜底) |
| 详情页黑屏/转圈 | 相机预热需几秒;分辨率过高带宽不足;重进页面;必要时恢复出厂分辨率(VGA 640×480)再试 |
| 切分辨率后花屏/多画面伪影 | 旧版只 set_framesize + 丢帧,GC2145 DMA 残留拼出残影;0.2.4 起改为 **deinit+init 重建相机管线**后按当前设置重放翻转/镜像,切换后画面正常 |
| 切分辨率后画面大小不变(所有档位看起来一个样,0.2.4) | 0.2.4 只在重建**失败回退**分支更新 `config.frame_size`,成功路径从不更新 → `esp_camera_init` 始终按启动尺寸 init。**0.2.5 修复:`rebuildCamera()` 每次重建前从全局设置同步 `config.frame_size` / `config.jpeg_quality`,需重烧 0.2.5** |
| 垂直翻转/水平镜像不生效 | 旧版经 `s->set_vflip/set_hmirror`,部分驱动(esp_cam_sensor)实现是坏的(NEW 驱动把 vflip 误写 reg 0x10 = 窗口宽度低字节,既不改翻转还破坏宽度);0.2.4 起改用寄存器级 `s->set_reg(0x17, bit1/bit0)` 且每次 init 后重放 |
| 录像提示"无画面" | 首帧 5 秒内没到:确认设备在线、先让画面出来再点录像 |
| 录像保存失败 | 检查 `Movies/LabHub` 目录可写;低端机编码慢属预期,换小分辨率 |
| 截图保存失败 | API ≤28 需先授予存储权限;检查 `Pictures/LabHub` 是否被系统清理 |
